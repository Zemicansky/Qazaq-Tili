# 🏔️ Qazaq Tili — Казахский язык

Мобильное PWA-приложение для изучения казахского языка на русском языке. Вдохновлено Duolingo: удобный интерфейс, интервальные повторения, ИИ-чат, стрик дней.

## ✨ Что умеет

- **Тренажёр слов** — режимы Рус → Каз и Каз → Рус (выбор из вариантов или свободный ввод с толерантностью к опечаткам). Более 2500 слов по темам.
- **Интервальные повторения (SRS)** — слова возвращаются на повторение через 10 мин / 4 ч / 2 дня / неделю, сложные слова приоритизируются.
- **Дневная цель** — настраиваемая (5–100 слов/день), с оценкой «слов в неделю/месяц» и прогресс-баром.
- **Стрик дней** — анимированный бейдж с рекордом серии и предупреждением, если цель на сегодня ещё не выполнена.
- **Словарь по темам** — еда, числа, цвета, транспорт, эмоции и др., с внешним поиском (Wiktionary/MyMemory/Glosbe).
- **Диалоги** — 50 реальных ситуаций с вопросами на понимание.
- **Грамматика** — справочник по аффиксам, падежам, спряжениям.
- **ИИ-чат** — перевод и исправление ошибок через OpenRouter (бесплатно).
- **TTS** — озвучка через Web Speech API (голос ОС/браузера).
- **Статистика** — прогресс по темам, недельная активность, история серии.
- **Тёмная тема** + PWA (добавляется на рабочий стол Android/iOS).

## 🗂️ Стек

| Слой | Технологии |
|---|---|
| Frontend | Vanilla HTML / CSS / JS (без фреймворков), разнесено по файлам |
| Хранилище | `localStorage` |
| TTS | Web Speech API (голос ОС/браузера) |
| ИИ-чат | OpenRouter API (Gemini, Qwen, LLaMA — free tier, с автопереключением моделей) |
| Шрифт | Google Fonts — Nunito |
| Деплой | Любой статик-хостинг (GitHub Pages, Netlify, Vercel) |

## 🗂️ Структура проекта

```
index.html   — разметка (HTML)
style.css    — все стили
app.js       — вся логика приложения
sw.js        — Service Worker (офлайн-кэш + уведомления-напоминания)
README.md    — этот файл
```

Раньше всё лежало в одном `index.html`. Файл разделён на 3 части для
удобства разработки — `sw.js` уже был готов к этому заранее (кэширует
`index.html`, `style.css` и `app.js` по отдельности, версионирует каждый
по хэшу содержимого).

## 🚀 Запуск

Никакого билда не нужно — всё та же ванильная связка HTML/CSS/JS,
теперь в 3 файлах вместо одного. Достаточно, чтобы все 4 файла
(`index.html`, `style.css`, `app.js`, `sw.js`) лежали рядом в одной папке.

```
# Локально
open index.html

# GitHub Pages
# Просто push всю папку (index.html, style.css, app.js, sw.js)
# в репозиторий и включи Pages в настройках
```

⚠️ Важно: `sw.js` регистрируется по относительному пути `./sw.js` и
ожидает найти `./style.css` и `./app.js` рядом с `index.html` — при
деплое переносите все 4 файла вместе, не только `index.html`.

## 🔑 Опциональные ключи (в настройках приложения)

- **OpenRouter** — для ИИ-чата. Бесплатный ключ: [openrouter.ai](https://openrouter.ai)

Ключ хранится только в `localStorage` браузера пользователя и передаётся только в заголовке запроса к OpenRouter.

## 📖 Как добавить в базу новые слова

Слова хранятся в массиве `WORDS` внутри `app.js`. Формат:

```js
{ id: 999, kz: "Сәлем", ru: "Привет", topic: "greeting",
  example_kz: "Сәлем, қалайсыз?", example_ru: "Привет, как дела?" }
```

Темы — в массиве `TOPICS`.

## 💡 Подключение полного казахского словаря

Встроенный словарь (2500+ слов) покрывает основные темы. Если нужен полноценный словарь казахского языка, можно подключить один из открытых источников:

- **[sozdik.kz](https://sozdik.kz)** — крупнейший онлайн-словарь. API не публичный, но можно парсить или договориться.
- **Apertium kaz-rus** — открытый машинный переводчик с казахского, есть датасеты на GitHub ([apertium/apertium-kaz](https://github.com/apertium/apertium-kaz)).
- **Wiktionary dump** — свободные данные, кз-раздел содержит тысячи слов с переводами (уже используется как резервный источник в поиске по словарю).
- **KazakhNLP** — NLP-ресурсы на казахском, в том числе частотные словари.

Наиболее реалистичный путь без бэкенда: скачать готовый JSON-словарь из открытых датасетов (например, репозиторий [kz-words](https://github.com/search?q=kazakh+dictionary+json)) и добавить его в массив `WORDS`, либо загружать через `fetch` при старте.
