# 🏔️ Qazaq Tili — Казахский язык

Мобильное PWA-приложение для изучения казахского языка на русском языке. Вдохновлено Duolingo: удобный интерфейс, интервальные повторения, ИИ-чат.

## ✨ Что умеет

- **Тренажёр слов** — три режима: Рус → Каз, Каз → Рус, Аудио. Более 700 слов по темам.
- **Интервальные повторения (SRS)** — слова возвращаются на повторение через 10 мин / 4 ч / 2 дня / неделю.
- **Словарь по темам** — еда, числа, цвета, транспорт, эмоции и др.
- **Диалоги** — 50 реальных ситуаций с вопросами на понимание.
- **Грамматика** — справочник по аффиксам, падежам, спряжениям.
- **ИИ-чат** — перевод и исправление ошибок через OpenRouter (бесплатно).
- **TTS** — озвучка через Web Speech API или ElevenLabs (настоящий казахский голос).
- **Статистика** — прогресс по темам, стрик, недельная активность.
- **Тёмная тема** + PWA (добавляется на рабочий стол Android/iOS).

## 🗂️ Стек

| Слой | Технологии |
|---|---|
| Frontend | Vanilla HTML / CSS / JS (без фреймворков) |
| Хранилище | `localStorage` |
| TTS | Web Speech API + ElevenLabs API (опционально) |
| ИИ-чат | OpenRouter API (Qwen, DeepSeek, LLaMA — free tier) |
| Шрифт | Google Fonts — Nunito |
| Деплой | Любой статик-хостинг (GitHub Pages, Netlify, Vercel) |

## 🚀 Запуск

Приложение — один файл `index.html`. Достаточно открыть его в браузере или положить на любой статик-хостинг. Никакого билда не нужно.

```
# Локально
open index.html

# GitHub Pages
# Просто push index.html в репозиторий и включи Pages в настройках
```

## 🔑 Опциональные ключи (в настройках приложения)

- **OpenRouter** — для ИИ-чата. Бесплатный ключ: [openrouter.ai](https://openrouter.ai)
- **ElevenLabs** — для настоящего казахского голоса. Бесплатный ключ: [elevenlabs.io](https://elevenlabs.io)

Ключи хранятся только в `localStorage` браузера пользователя.

## 📖 Как добавить в базу новые слова

Слова хранятся в массиве `WORDS` внутри `index.html`. Формат:

```js
{ id: 999, kz: "Сәлем", ru: "Привет", topic: "greeting",
  example_kz: "Сәлем, қалайсыз?", example_ru: "Привет, как дела?" }
```

Темы — в массиве `TOPICS`.

## 💡 Подключение полного казахского словаря

Встроенный словарь (700+ слов) покрывает основные темы. Если нужен полноценный словарь казахского языка, можно подключить один из открытых источников:

- **[sozdik.kz](https://sozdik.kz)** — крупнейший онлайн-словарь. API не публичный, но можно парсить или договориться.
- **Apertium kaz-rus** — открытый машинный переводчик с казахского, есть датасеты на GitHub ([apertium/apertium-kaz](https://github.com/apertium/apertium-kaz)).
- **Wiktionary dump** — свободные данные, кз-раздел содержит тысячи слов с переводами.
- **KazakhNLP** — NLP-ресурсы на казахском, в том числе частотные словари.

Наиболее реалистичный путь без бэкенда: скачать готовый JSON-словарь из открытых датасетов (например, репозиторий [kz-words](https://github.com/search?q=kazakh+dictionary+json)) и добавить его в массив `WORDS`, либо загружать через `fetch` при старте.
